## Production notes

- **Voice:** Edge TTS `AndrewMultilingualNeural` (en-US). For Spanish we have `es-MX-JorgeNeural`.
- **Pacing:** 1s negative-space at start of each scene. Last scene has 2s tail silence.
- **Captions:** one display phrase per scene, fade-in 30-40% through, hold to end. Font: InterTight-Bold.
- **Image anchor policy:** Each scene's PDF page becomes the visual anchor (3-4s up front, recurs as closing shot).
- **Video b-roll policy:** Grok Imagine, 4-6s fragments, dark/premium aesthetic, 720p, no on-screen text (we layer our own).
- **No hype:** avoid "revolutionary", "transformative", "disruptive", "magic", "frequency healing". Voice is calm, evidence-based, premium.
